# 离线恢复管理员密码

此操作用于忘记 Owner 密码。必须先停止应用服务，然后在使用同一数据卷和主密钥的主应用容器中运行维护命令。恢复会撤销全部现有会话；所有客户端都需要重新登录。

1. 停止主应用服务，并确认没有其他进程使用数据目录。不要删除数据卷、数据库或主密钥。
2. 在受控位置创建密码文件，将其以只读方式挂载到主应用容器的 `/run/secrets/admin-reset`。文件须为容器运行用户可读的普通文件，权限不得允许组或其他用户访问，例如 `0600`。不得使用符号链接。文件最大 4096 字节；内容为 UTF-8 新密码，可带一个末尾换行。密码至少 12 个字符，最多 1024 个字符。不要将密码写入命令行、环境变量或日志。
3. 使用与主应用相同的镜像、用户、数据卷及主密钥挂载，启动一次性维护容器，执行：

   ```sh
   node dist/control/admin-recovery.js --data-dir /data --username owner --password-file /run/secrets/admin-reset --confirm-reset
   ```

   将 `owner` 替换为现有 Owner 的确切用户名。若部署使用 `HDA_MASTER_KEY_FILE`，维护容器也须指向相同的主密钥文件。命令只适用于已初始化的数据；主密钥丢失时须从安全备份恢复原密钥。不要生成新密钥替代它。
4. 命令成功后移除临时密码文件及挂载，重新启动应用，并用新密码登录。命令失败时保留原数据，检查服务是否停止、用户名、密码文件权限、数据库和主密钥后重试。

维护命令持有应用所有权锁及数据库锁。它不会提供 HTTP 重置接口，也不会读取标准输入。部署配置中的具体容器运行命令须确保上述挂载和服务停止条件成立。
