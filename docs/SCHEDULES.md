# 通用定时代理任务

由你提供提示词、执行时间和推送目标。调度器不预设股票或科技业务。代理到点使用当前已配置的工具执行任务，每次运行创建独立会话并加载所属身份的最新记忆。

## 在 Bot 中创建

配置模型与渠道后，在普通私聊中发送：

> 请创建一个定时任务：每个工作日北京时间 08:00，搜索过去 24 小时的全球科技信息，筛选最重要的 8 条。每条说明事件并附来源链接，无法核实的内容要标明。完成后发到这个私聊。

也可以要求每周整理工作区文档、检查项目记录等。模型通过 schedule_create 保存任务。只有工具成功才算已创建。任务继承当前会话的身份、工作区和来源渠道。

可继续要求列出任务、查询运行记录、暂停、恢复、取消当前运行或立即执行一次。定时运行本身不能再创建或修改其他定时任务，避免递归扩张。

## 联网配置

```sh
export OPENAI_API_KEY='你的模型凭据'
export BRAVE_SEARCH_API_KEY='你的 Brave Search API key'
npm start -- daemon
```

Brave API：https://brave.com/search/api/ 。本项目不会自动读取 .env 文件，需要导出环境变量，并重启 daemon 加载配置。

web_search 最多返回 8 条结果，包含来源 URL、摘要与检索时间。freshness 可为 pd、pw、pm、py，即过去一天、一周、一月、一年。搜索摘要不等于已核实正文，网页搜索也不等于专用行情数据源。

web_fetch 不需要搜索 key，支持公开静态 HTML 和 UTF-8 文本，返回正文、标题、最终 URL 和检索时间。不执行网页脚本，不支持登录、PDF 或浏览器渲染。

status 中 capabilities.webSearchConfigured 只表示是否配置 key，不表示账号和网络已验证。

## CLI 创建

```sh
npm start -- schedule create '搜索过去 24 小时的科技信息，筛选 8 条并引用来源。' \
  --name '科技简报' --cron '0 8 * * 1-5' --timezone Asia/Shanghai
```

支持五段 cron（分、时、日、月、周），按 IANA 时区计算并处理夏令时。例如每天 08:00 为 `0 8 * * *`，每周五 18:00 为 `0 18 * * 5`。不支持六段秒级表达式。

一次性任务使用未来的、包含 Z 或 UTC 偏移的 ISO 时间，与 cron 二选一：

```sh
npm start -- schedule create '读取项目文档并给出待办清单。' \
  --name '项目检查' --at '2027-01-01T08:00:00+08:00'
```

示例日期需要替换为实际未来时间。

CLI 默认使用 local 身份，结果写入本地收件箱。需要发回已有私聊时，增加 `--conversation 123`，将 123 替换为原私聊的会话 ID。程序沿用该会话的身份、工作区和来源渠道，不接受任意用户号码作为新目的地。

## 管理

```sh
npm start -- schedule list
npm start -- schedule get <任务ID>
npm start -- schedule runs <任务ID>
npm start -- schedule pause <任务ID>
npm start -- schedule resume <任务ID>
npm start -- schedule run <任务ID>
npm start -- schedule cancel <任务ID>
npm start -- inbox
npm start -- deliveries
```

默认操作 local。管理渠道任务时使用 `--scope '<身份作用域>'` 或 `--conversation <原会话ID>`。runs 不指定任务 ID 时返回该身份最近 100 次运行。cancel 使用任务 ID，请求取消当前运行；未来周期需用 pause 停止。

- pause 不打断当前已接收的运行，也不撤回已排队的推送。
- resume 对周期任务从下一次未来时间开始；暂停的一次性任务若已过期则立即执行。已结束的一次性任务用 run 重跑。
- run 不改变周期或暂停状态，同一任务已有运行时拒绝重叠。
- cancel 先持久化取消标记，再由监控任务中止执行并释放运行名额。

管理请求可提供稳定 `--request-id`。相同身份、相同 ID 和相同参数不会重复创建或手动执行；同一个 ID 改用不同参数会被拒绝。模型工具自动使用持久化工具任务 ID 去重。

## 恢复与投递

任务、运行记录、会话关联、输入 ID 和检查点保存在现有 SQLite。重启不重复创建本次会话或输入；在途模型请求、搜索或网页读取仍可能按运行时恢复策略再次发起并产生费用。

停机错过多个周期时最多补跑一次，并记录原定时间与实际执行时间；下一触发时间在当前时间之后。同任务仍在执行时跳过本次触发，不积压运行队列。

完成或失败后先保存结果与唯一收件箱通知，再由现有渠道队列发送。运行 completed 不等于平台交付成功。unknown 仍需人工处理；WhatsApp 的 24 小时窗口和微信会话状态仍适用。移除渠道用户授权会阻止发送，但需要管理员另外暂停该用户已有的定时任务。

任务详情与运行记录保留会话 ID，可用现有 history 命令检查工具证据。备份恢复包含调度定义和运行状态。

## 限制

默认每次最多 8 轮工具调用、运行 300 秒、模型费用阈值 0.50 美元。CLI 可调整：

```sh
npm start -- schedule create '执行自定义提示词。' --cron '0 8 * * *' \
  --max-turns 6 --timeout-seconds 180 --max-cost-usd 0.25
```

轮数范围 1–12，时间范围 10–1800 秒，费用阈值范围 0.01–10 美元。每个身份最多保存 50 个任务，包含已完成的一次性任务。当前没有编辑或删除命令；变更提示词需暂停旧任务并创建新任务，暂停不释放额度。

费用阈值是依据已报告或估算模型费用检查的软限制，约每 250 ms 检查一次，无法撤销在途请求，不包含 Brave API 费用。价格缺失或报告滞后时不能作为严格预算上限。

联网请求只允许公开 HTTP(S) 标准端口，拒绝本机、私有、保留和混合 DNS 地址，固定已验证地址连接并逐次检查重定向。搜索凭据不随重定向转发。响应最多 1 MiB，正文最多 20000 字符；整条链有 20 秒期限，单次连接有 12 秒期限，最多 3 次重定向，并传递取消信号。
