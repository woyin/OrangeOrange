## 各阶段证据

### P0：持久化和恢复

`tests/ownership.test.ts` 验证另一个进程持锁时拒绝竞争者，并在 SIGKILL 后释放同一个锁文件上的锁。

`tests/recovery.test.ts` 使用独立进程验证：

1. 模型请求运行中 SIGKILL，重新打开后有限重试并得到答案；相同 requestId 仍为同一个 submission，只有一条用户输入记录。
2. 提醒等待期间 SIGKILL，恢复后只创建一条通知；交付后再次 SIGKILL，通知数量不变；已读状态跨重启保留。
3. 自定义任务进入 work 阶段后 SIGKILL，下一进程用 v2 定义迁移 v1 检查点，只提交一条完成记录；再次重启不重复提交。

第三项验证的是 Durable 任务迁移机制。正式应用任务目前仍为 v1；并未声称未来任意升级都可自动迁移。

### P1：服务和 CLI

`tests/cli.test.ts` 验证实际子进程 CLI 访问本地 socket、目录和 socket 权限、第二个 daemon 拒绝启动、取消活动模型请求、客户端稍后查询已完成结果、优雅停止以及备份恢复。

无凭据时，模型输入提交明确失败，离线记忆管理仍可使用。

索引文件损坏导致启动失败后，服务释放所有权。移走派生索引后可以重新启动，原始记忆不丢失。

### P2：工作区和技能

`tests/workspace.test.ts` 覆盖 UTF-8 中文文件、父目录穿越、绝对路径越界、文件及目录符号链接越界、普通文件类型、二进制内容和大小限制。

`tests/skills.test.ts` 覆盖描述扫描、正文加载、未知技能和目录外技能链接。

`tests/tools.test.ts` 验证 Durable 的实际工具循环能调用 read_file、skill_load 和 reminder_create，并在工具结果或持久化状态中查证结果。没有启用真实外部模型。

### P3：记忆和历史

`tests/memory.test.ts` 验证模型工具写入、创建新会话时的提示词快照、旧会话快照保持、跨重启保存、删除和容量溢出回滚。

`tests/history.test.ts` 验证中文短词及英文查询、原文来源、分页、全量重建和删除派生索引后从原始记录恢复。

FTS5 使用中文单字切分和其他 Unicode 单词切分，AND 匹配。不提供语义检索或短语顺序保证。

### P4：提醒和运行限制

`tests/reminders.test.ts` 使用可控时钟验证提醒创建去重、同 ID 不同内容冲突、取消、过期交付、已读确认，以及缺少时区和非法日历日期的拒绝。

取消与交付以先提交者决定状态。交付后取消返回 delivered；取消先提交不产生通知。

`tests/tools.test.ts` 另外验证持续工具调用在 12 轮停止，持续模型错误在 2 次重试后结束。

### P5：安装、恢复和文档

`scripts/smoke-install.mjs` 在独立目录重新安装依赖并构建，通过编译后的 CLI 创建会话、管理记忆、读取技能和停止服务。脚本清理临时目录与子进程。

备份恢复测试使用实际备份文件恢复到新的数据目录，不覆盖已有数据。

`README.md` 提供启动、配置、输入去重、记忆快照、搜索、技能、提醒、备份恢复、运行限制与升级说明。`.env.example` 不包含真实凭据。

## 真实模型验收的准确补齐方式

在本机为测试进程配置合法 OpenAI API key 后执行：

```sh
npm run build
npm run smoke:live
```

脚本会在临时目录启动服务，用实际编译后的 CLI 验证模型调用记忆工具、文件工具、历史搜索工具和提醒工具，再重启服务核对记忆及收件箱状态。每次生成输出限制为 2048 token，每次 run 最多 12 轮；会产生真实 API 费用。

只有脚本返回 PASS，才能将三条用户流程标记为真实模型验收通过。若失败，应根据持久化记录定位原因，不以模型口头回答替代工具证据。

## 实际交付限制

- 服务是手动启动的前台 daemon，尚未安装 launchd 自启动项。
- 只支持本地单用户和 OpenAI API key；没有消息平台、远程 TCP、多用户或 OAuth 接入。
- 不包含 Shell、文件修改、浏览器、MCP、子代理、自动技能学习和周期 cron。
- 取消的休眠提醒可以保留到原截止时间，但不会生成通知。
- 不保证系统休眠时准点执行，不保证断电后最新提交存活，不保证外部副作用恰好一次。
- 工作区不是 OS 沙箱；尚未验证其他进程恶意并发替换目录结构的场景。
- 依赖实验性 Pi Durable 和 Node SQLite；升级前需备份并验证旧任务。
- 尚未进行长期运行、海量历史、多客户端压力或跨操作系统验证。
