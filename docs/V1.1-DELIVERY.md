# V1.1 交付操作入口
## OpenAI 兼容服务配置

提供商类型选择`openai`；URL填写在单独的“API 地址”中，不要把URL写入提供商类型。

| 字段 | 填写方式 |
|---|---|
| 模型提供商 | `openai` |
| API 地址 | 服务商给出的基础地址，通常以`/v1`结尾；留空使用官方接口 |
| 模型 ID | 服务商给出的完整模型名；填写API地址时不要求在内置目录中 |
| 模型密钥 | 对应服务商签发的密钥 |

自定义地址使用`/chat/completions`流式协议。只提供Responses或其他协议的服务尚不在此兼容范围。留空API地址时仍使用官方接口，模型ID须在内置目录中，否则返回`UNSUPPORTED_MODEL`。

自定义模型未填写上限时使用上下文32768、单次输出4096；可在模型设置中调整，输出不能超过上下文。代理实际价格可能不同于内置参考价，因此自定义模型默认“价格未知”：此时Token上限仍生效，但若设置了金额预算，任务会以`BUDGET_PRICE_UNKNOWN`失败，直到填写每百万Token的输入和输出单价。填写单价后金额预算按该单价估算，估算不能代替服务商账单。

首次配置和“模型与预算”的编辑入口均支持地址、上限和单价。清空API地址可切回官方接口；URL不能含账号、密码、查询参数或片段。
