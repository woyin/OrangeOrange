## 实现

- ScheduleState 保存任务、运行和操作去重记录，复用现有 SQLite 与单实例锁。
- orange.schedule 负责周期触发；orange.scheduled-run 负责独立会话、输入提交、监控和结果保存。
- 支持未来一次性时间和五段 cron，每次加载最新记忆，同一任务禁止重叠。
- 触发与运行记录、会话与运行关联、输入与输入 ID 分别在对应的提交中原子保存。
- 暂停、恢复、手动运行、取消与最近 100 次运行查询均有 CLI 和模型工具入口，工具身份来自会话 Profile。
- 管理工具使用持久化操作 ID，避免提交后重放重复执行；CLI 可指定 request-id。
- 结果与唯一通知原子保存，再经来源渠道投递；继续遵守 unknown 不自动重发规则。
- web_search 使用 Brave Search API；web_fetch 读取公开静态网页，并限制地址、重定向、响应大小、超时和取消。

## 测试证据

`tests/schedules.test.ts` 共 11 项：

1. 时区、工作日、夏令时与错误 cron。
2. 提示词经过 Durable 工具循环读取文件，使用最新记忆，唯一保存结果，管理请求去重。
3. 暂停/恢复、身份隔离、重叠拒绝与取消。
4. 跨停机错过多个周期只补跑一次。
5. 超时中止模型并释放运行名额。
6. 注入已报告费用账本，验证费用监控中止运行。模型替身本身费用固定为零，不能靠修改响应费用模拟真实计费。
7. 普通对话通过工具创建任务，定时运行拒绝递归管理任务。
8. 模型请求中 SIGKILL 后恢复同一运行、会话与输入，唯一保存结果；不声称在途模型请求只收费一次。
9. 搜索和网页工具组成通用执行链，并保存来源证据；搜索 key 不进入结果或历史。
10. 结果向来源私聊投递一次，重复通知扫描不重复入队。
11. 无效时间、预算、冲突规则与并发重复操作 ID。

`tests/web.test.ts` 和 `tests/web-http.test.ts` 共 6 项，覆盖私有与保留地址、IPv4 映射 IPv6、混合 DNS、凭据 URL、端口、HTML 提取、输出截断、搜索参数与缺少 key、DNS 固定、重定向拒绝、响应大小和类型，以及搜索凭据不随重定向转发。HTTP 测试采用协议替身，不代表公网连通。

`tests/cli.test.ts` 新增实际子进程 CLI 调度流程，并扩展备份恢复验证，确认调度定义可恢复。其余已有回归也在本轮重新通过。

## 实际边界

费用阈值采用独立监控任务。底层会隔离扩展钩子异常，不能把钩子抛错当成硬拦截。费用检查有延迟，限于已报告/估算模型费用，不包含 Brave 费用。

真实公网读取被系统 DNS 阻塞。lookup 与 resolve4 均观察到保留地址分类。需要可解析到真实公网地址的出站网络；当前客户端不支持 HTTP_PROXY 转发。

缺少模型凭据的 BLOCKED 不等于真实模型通过。默认提示词遵循程度、摘要质量、真实 Brave API 与平台投递仍需实际验收。

任务仅能使用现有工具，不支持登录网页、浏览器渲染、媒体、Shell 或任意文件修改。当前最多 50 个已保存任务/身份，尚无编辑和删除命令。暂停旧任务后可创建替代任务，但暂停不释放额度。
